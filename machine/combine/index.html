小型機械・作業機・農業機械の修理相談ガイド

コンバイン修理の相談先と費用例

収穫の途中で止まった、いつもの店に頼めない。使う予定日を伝えるとともに、その型式・購入経路での受付と、現場からの引取が必要な場合の対応を確かめましょう。

止まった機械は、状態を伝えて相談

詰まりや異音など、すでに気づいている状態を伝えます。自分で詰まりを取り除いたり、点検のために駆動部へ触れたりせず、機械の取扱説明書に従って安全を確保し、修理窓口に相談してください。

症状を確かめるための再始動や分解はせず、すでに気づいている状態を伝えてください。刃・駆動部・燃料系統などに無理に触れず、安全に読めない銘板や確認できない項目は「不明」のまま相談できます。

田んぼで動かない場合に確認すること

  • 現場の市町村、田んぼ・倉庫などの置き場所と進入条件。
  • 型式、分かれば条数、走行できるかどうか。
  • 出張点検・搬出・工場への引取をそれぞれ頼めるか。
  • 引取と納品の費用、部品の納期、使用予定日に間に合う見通し。

日程や現地作業の可否は、窓口からの回答を受けて判断します。農繁期前の準備もご覧ください。

コンバインの公式整備料金例

JAいせの令和8年料金表では、修理工賃は1人1時間6,600円、出張料は2,200円です（消費税込み）[1]。部品代や運搬費を含む修理総額ではありません。

JAグループ佐賀の2条刈コンバインの技術料金は基準58,000円から、予約40,000円からです。3条刈は基準79,000円から、予約54,000円からです[2]。

JAグループ佐賀の農業機械整備の参考価格です。消費税込みの技術料金で、部品代・油脂代は含みません。機械の状態により適用できない場合があります。引取・納品は技術料とは別にそれぞれ1台5,000円（税別）との案内です。今回の故障の見積額や、千葉県の相場を示すものではありません。予約の適用条件も依頼先にご確認ください[2]。

他店購入・中古品も購入経路を伝える

中古での購入、購入店の閉店、ネット購入などの経緯を最初に伝えます。メーカーの販売店でも当該機種の受付は確認が必要です。購入店不明・他店購入の相談方法とメーカー公式窓口を確認してください。

相談前のチェックリスト

  1. 機械の種類と動力草刈機・刈払機などの種類と、エンジン式か電動式か。
  2. メーカー・型番分かる範囲で記録。銘板が安全に見える場合は写真も用意します。
  3. 症状と発生時期動かない、異音がするなど、すでに気づいていること。原因の特定は不要です。
  4. 機械のあるエリア市町村と置き場所。詳しい住所は相談先へ必要な範囲で伝えます。
  5. 購入経路と使用歴購入店不明・他店・ネット購入のどれか、中古品か、分かれば年式も。
  6. 持込か出張か持ち込みできるか、出張・引き取りを希望するか。

千葉県の修理先について

千葉県の修理先一覧は準備中です。

最初に草刈機・刈払機について、対応メーカー・型番、他店／ネット購入、持込・出張の条件を確認します。現在、条件を指定した業者検索や、このサイトでの修理受付は利用できません。

お急ぎの場合は、メーカーの公式案内から相談先を探し、受付条件を直接ご確認ください。

よくある質問

コンバインの整備料金はいくらですか？

公開料金表の例では、JAグループ佐賀の点検整備の技術料金が、2条刈で基準58,000円から（予約40,000円から）、3条刈で基準79,000円から（予約54,000円から）です。税込の技術料金で、部品代・油脂代は含みません。

田んぼで止まったコンバインも見てもらえますか？

出張点検や引取に対応するかは依頼先ごとに違います。置き場所と進入条件、走行できるかを伝えて相談してください。自分で詰まりを取ったり駆動部に触れたりはしないでください。

他店や中古で買ったコンバインの修理先は？

受け付けるかは依頼先の条件によります。型式と購入経路を最初に伝え、受付できるかを確認してください。
